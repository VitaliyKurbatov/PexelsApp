# PexelsApp
Test application for iOS. Contains a feed with photos downloaded from the open source www.pexels.com/api.
The API is rate-limited to 200 requests per hour.

Тестовый проект для iOS. Содержит ленту с фотографиями, загружаемыми из открытого источника www.pexels.com/api.
Имеет ограничение по количеству запросов: не более 200 в час.
